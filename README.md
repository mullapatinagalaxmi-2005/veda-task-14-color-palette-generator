# 🎨 Veda Technology – Task 14: Color Palette Generator

## 📌 Project Overview

The **Color Palette Generator** is a responsive web application developed using HTML, CSS, and JavaScript as part of the Veda Technology Web Development Internship.

This application generates five random HEX color codes and allows users to copy their favorite color code to the clipboard with a single click.

## ✨ Features

- 🎨 Generates five random HEX colors.
- 🖼️ Displays colors in visual swatch cards.
- 📋 Copies HEX color codes with one click.
- ✅ Displays a confirmation message after copying.
- 🔄 Generates a new palette whenever the button is clicked.
- 📱 Responsive design for desktop and mobile devices.
- ♿ Includes accessible button labels and status messages.

## 🛠️ Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling, layout, and responsive design
- **JavaScript** – Random color generation and interactive functionality
- **Clipboard API** – Copying HEX codes

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Install the Live Server extension if necessary.
4. Right-click `index.html`.
5. Select **Open with Live Server**.
6. Click **Generate New Palette** to generate five random colors.
7. Click any color card to copy its HEX code.

## ⚙️ How It Works

1. JavaScript generates random hexadecimal color codes.
2. The generated colors are displayed as visual cards.
3. Clicking a card copies its HEX code to the clipboard.
4. A confirmation message appears when copying succeeds.
5. Users can generate a new set of colors whenever they want.
